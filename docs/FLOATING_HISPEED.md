# フローティングハイスピード

鍵盤モード別に使える、初期状態OFFの速度方式です。本体の「BMS-IR固有設定」で
対象モードを選び、「フローティングハイスピード」をONにします。通常・コンパクトの
オーバーレイにも同じ設定があります。プレイ中の方式切り替えは次のプレイから適用します。
ONのモードでは、通常のHI-SPEED FIXとLR2ハイスピ固定より優先します。
OFFにすると元の通常・LR2設定を使います。

## 操作

- 倍率は0.50～10.00。START＋黒鍵で＋0.50、白鍵で−0.50。
  START＋6/7の別カバー操作設定より、この鍵盤操作を優先します。
- START＋皿は、表示中のSUDDEN、HIDDEN、LIFTの順で対象を選びます。
  SUDDENとHIDDENを併用しているときは同時に動かします。
- カバーがない場合の皿は倍率の微調整になります。
  アナログ入力1カウントあたり1/150倍。デジタル皿は50msごとに1カウントです。
  機器が返すカウント数・回転方向は既存入力設定に従います。
- START二度押しは234ms未満で上・下カバーを表示／非表示にします。
  LIFTは残ります。通常方式の二度押し間隔とSTART＋SELECT操作はそのままです。
- SELECT＋鍵盤／皿は保存可視時間の調整になります。

## 保存緑数字と表示

曲開始時に有効なカバーがあれば、保存可視時間と開始BPMから倍率を計算します。
鍵盤で倍率を変えても保存緑数字は更新しません。その後カバーを皿で動かすと、
保存した可視時間へ戻るように倍率を再計算します。倍率上限・下限に当たる場合は
緑数字を完全には維持できません。

カバーなしの皿操作は、変更後の可視時間を保存します。
SUDDENとLIFTを併用しSUDDENを隠しているときは、LIFTの皿操作で倍率を再計算しません。
再表示時は、非表示前に保存した可視範囲からSUDDENの位置を戻し、可視時間を保存します。

保存値は丸め前の可視時間です。表示緑数字は60Hz基準の可視フレーム数を10倍して
切り上げます。HIDDENも可視範囲から引きます。最小・最大BPMの緑数字も同じ計算です。
カバーなし、倍率2.00、BPM150では緑数字583、90/723の上カバーでは511です。

倍率を変えずにBPMが半分になると緑数字はおよそ2倍になります。
BPM変化だけでは倍率や保存緑数字を更新しません。BMSのSTOP・SCROLLは既存の
譜面描画に従い、可視時間表示は現在のBPM・SCROLLから求めます。
無効なBPM・SCROLLでは表示0として除算を避けます。

速度変更は60Hz換算の時間で補間し、描画フレームレートに依存させません。
カバーがある場合は16フレーム相当のsin補間、ない場合は残差を毎フレーム約9.8%ずつ縮めます。
緑数字・倍率の表示には目標値を使います。

## 互換性と検証

通常倍率・HI-SPEED FIX値・通常の保存デュレーションとは独立して保存します。
`bmsir_arena.json` schema 23にも鍵盤モード別の値を記録します。
古い設定の読み込みはOFFで、旧`fixhispeed=5`の変換も維持します。
リプレイは初期値と操作中の倍率・可視時間・カバー表示を記録し、通常の表示復元設定に従います。
NO SPEED制約では無効です。判定・スコア・IR送信条件を変更しません。

回帰確認: `BMSIRFloatingHispeedTest`、`ReplayLaneMetricsTest`、
`BMSPlayerLiveLaneSettingsTest`、`BMSIRArenaConfigStoreTest`、設定FXML・日本語/英語リソース。
実機の操作・表示確認とバイナリ配布は別フェーズです。
